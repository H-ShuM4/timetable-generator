# 時間割自動生成システム

事務局で管理している **カリキュラム一覧** と **教員一覧** の Excel から、経営学科・会計学科・短期大学部の時間割を自動で作成します。

- 出来上がった時間割は画面で確認でき、気になる科目はマウスで別の曜日・時限へ動かせます
- **PDF**（学生への配布用）と **Excel**（編集用）で書き出せます
- このシステムは **このパソコンの中だけで動きます**。時間割のデータが外部へ送られることはありません（AI モードを使う場合を除く。詳しくは [生成](#2-生成) の項をご覧ください）

> **事務局の方へ** — [1. 使いはじめる前に](#1-使いはじめる前に) から順にお読みください。
> **開発の方へ** — [7. 開発者向け](#7-開発者向け) をご覧ください。

## 1. 使いはじめる前に

このパソコンに **Python（パイソン）** というソフトが入っている必要があります。システムを動かすための土台になるもので、無料です。

入っているか分からない場合は、そのまま [2. 最初の準備](#2-最初の準備) へ進んでください。入っていなければ画面が教えてくれます。

<details>
<summary>入っていなかった場合の入れ方</summary>

1. https://www.python.org/downloads/windows/ を開く
2. 「Download Python 3.○○」と書かれたボタンから入手する
3. 入れる途中で **「Add python.exe to PATH」** という項目に必ずチェックを入れてから進む

> ⚠️ 3 のチェックを入れ忘れると動きません。

情報システム担当の方がいる場合は、この作業をお願いしてください。

</details>

## 2. 最初の準備

**パソコン 1 台につき 1 回だけ**の作業です。

> **`setup.bat` をダブルクリックしてください。**

黒い画面が開き、システムに必要な部品を自動で取り込みます。数百メガバイトの通信が発生するため、数分かかります。**この作業のときだけインターネット接続が必要です。**

終わると `Setup complete.` と表示されます。何かキーを押すと画面が閉じます。

---

## 3. 毎日の使い方

> **`start.bat` をダブルクリックしてください。**

黒い画面が開き、数秒後にブラウザが自動で立ち上がります。自動で開かない場合は、ブラウザのアドレス欄に次を入力してください。

```
http://localhost:8000/
```

> ⚠️ **黒い画面は閉じないでください。**
> この黒い画面がシステム本体です。閉じると時間割の画面も使えなくなります。作業が終わったら閉じて構いません。

**使い終わるとき** — 黒い画面を閉じるか、黒い画面の上で `Ctrl` キーと `C` キーを同時に押してください。

<details>
<summary>「port 8000 is already in use」と出たとき</summary>

すでにシステムが起動しています。別の黒い画面が開いていないか探してください。見当たらない場合は、このフォルダーを開いてアドレス欄に `cmd` と入力し、開いた画面で次のように打ちます。

```
start.bat 8001
```

この場合、ブラウザの住所は `http://localhost:8001/` になります。

</details>

## 4. 画面の使い方

画面は上部の見出しで切り替えます。左から順に進めてください。

### 1 ファイル読込

カリキュラム一覧と教員一覧の Excel を、点線の枠の中へドラッグ＆ドロップし、**「読み込む」** を押します。

読み込むと、科目数・教員数などの集計が表示されます。数字が普段の感覚と大きく違う場合は、Excel の中身を確認してください。

データに気になる点があると「警告」として一覧に出ます。**警告が出ても時間割は作れます。** 参考情報としてご覧ください。

> 例）`担当科目がありますが出勤可能日が空欄です: ○○先生`
> → 教員一覧でその先生の出勤可能日を埋めると、より適切に配置されます。

<details>
<summary>踏襲モードを使う場合（前年度を引き継ぐ場合）</summary>

上の 2 本に加えて、次の 2 本も一緒に投入してください。

| ファイル         | 内容                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| 前年度の時間割   | カリキュラム一覧と同じ列の並びで、曜日と時限が埋まっているもの。去年つくった時間割の Excel です |
| 前年度の教員一覧 | 去年の教員一覧です。研究日が変わった先生を見つけるために使います                                |

> ⚠️ どちらか片方だけでは、1 件も引き継がれません。2 本そろっていないと、踏襲モードは選べないようにしてあります。

投入すると、ファイルごとに役割を選ぶ欄が出ます。ファイル名に「前年度」が入っていれば自動で割り当たります。入っていない場合は、この欄で選び直してください。

読み込んだあと「前年度の時間割」「前年度の教員一覧」がどちらも **あり** になっていることを確かめてください。

</details>

**前回の続きから** — ブラウザを閉じたり、パソコンを再起動したりしても、前回読み込んだデータと作成した時間割は残っています。次に開いたときに自動で復元され、画面上部に「前回の読み込みデータと生成結果を復元しました。」と出ます。別の Excel を読み込むと、そちらに切り替わります。

### 2 生成

作り方を選んで **「生成を開始」** を押します。

| モード                             | 何をするか                                                           | かかる時間           | 要るもの            |
| ---------------------------------- | -------------------------------------------------------------------- | -------------------- | ------------------- |
| **モックモード**（ふだんはこちら） | このパソコンの中だけで組み立てる。インターネットも AI も使わない     | 10 秒ほど            | —                   |
| **AI モード**                      | Google の AI（Gemini）に配置を考えさせ、残りをこのパソコンで埋める   | 数分                 | API キー            |
| **踏襲モード**                     | 前年度の時間割をそのまま引き継ぎ、組み替えが必要な科目だけを組み直す | 組み替えの方法による | 前年度の 2 ファイル |

> ⚠️ **AI モードでは、科目名・教員名・開講期といった情報が Google のサービスへ送られます。**
> 事前に「設定」で API キーの登録が必要です。

<details>
<summary>踏襲モードの詳しい使い方</summary>

「1 ファイル読込」で前年度の 2 本を読み込んでいないと選べません。選べない場合は、何が足りないかがモードの下に表示されます。

選ぶと **「組み替え対象」** の一覧が出ます。ここにチェックが付いている科目だけが組み替えられ、外した科目は前年度と同じ曜日・時限に固定されます。

その上にある **「組み替えの方法」** で、組み替える科目をどうやって置くかを選べます。

| 選択肢                         | 内容                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------ |
| このパソコンで配置する（数秒） | ふだんはこちら                                                                 |
| AI に考えてもらう（数分）      | 前年度の枠が使えなかった科目を Gemini に考えさせます。API キーの登録が必要です |

次の科目が **自動でチェック** されます。

- 非常勤、特任の先生の科目 — 出勤できる日が年度ごとに変わるため
- 研究日が去年と変わった専任の先生の科目
- 前年度に無かった新しい科目
- 担当の先生が変わった科目

一覧は理由ごとにまとまっています。見出しを押すと中身が開きます。「すべて選択」「すべて解除」でまとめて切り替えられます。

できあがった時間割では、前年度から引き継いだ科目の左端の線が **灰色** になります。

</details>

画面の下にログ（作業の記録）が流れます。今どの段階かを確認できます。終わると自動で「3 結果」へ移ります。

### 3 結果

学科と学期を選んで時間割を確認します。

#### 科目カードの見方

カードの左端にある細い縦線が、その科目の情報を表します。

**線の色 — 誰が置いたか**

| 色         | 意味                                       |
| ---------- | ------------------------------------------ |
| 黒に近い色 | Excel で曜日時限が指定済み（動かせません） |
| 濃い緑     | AI が配置                                  |
| 薄い緑     | システムが自動で配置                       |
| 山吹色     | あなたが手で動かした                       |
| 灰色       | 前年度から引き継いだ                       |

**線の高さ — いつ開講するか**

| 高さ         | 意味                       |
| ------------ | -------------------------- |
| 上から下まで | 学期を通して開講           |
| 上半分だけ   | 学期の前半だけ（前①・後①） |
| 下半分だけ   | 学期の後半だけ（前②・後②） |

カード左上の数字は年次です。色が濃いほど上の学年です。

<details>
<summary>同じコマに複数の科目が入っていても正常な場合</summary>

**【再】が付いた科目**
1 年生のときに単位を落とした人が受け直すクラスです。受けるのは 2 年生以降なので、同じ 1 年の必修と同じコマに入っていて構いません。（【再】どうしが重なることはありません）

**英語Ⅰ【A】【B】…、情報リテラシーⅠ【A】【B】… など**
1 つの科目を担当の先生ごとに分けたクラスです。学生はそのうち 1 つだけを受けるので、同じコマにまとめて構いません。

</details>

#### 科目を動かす

カードをつかんで、置きたいマスへ落としてください。決まりに反する場所へ落とすと、理由を示して断られます。

> 例）`松田流輝 の 水曜日が 4 コマ以上連続します`

経営学科と会計学科で合同開講の科目、および前期と後期で対になっている科目は、**片方を動かすともう片方も一緒に動きます。**

#### 右側の一覧

| 項目       | 内容                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 制約違反   | 決まりに反している箇所。赤い字で出ます。**0 件が正常です**                   |
| 未配置科目 | どうしても置けなかった科目。ここからマスへドラッグして手で置くこともできます |
| 集中講義   | 曜日・時限を持たない科目の一覧です                                           |

#### 出力

右上で形式を選んで **「出力」** を押します。ふだんは PDF です。

**PDF（印刷）**

押すと印刷の画面が開きます。「送り先」または「プリンター」で **「PDF として保存」** を選び、保存してください。

画面と同じ見た目のまま出ます。科目の左端にある色の線（どうやって決まったコマか）も、年次の色分けも残るので、学生へ配ったり掲示したりするのはこちらが向いています。

用紙は **A3 横**、1 ページに 1 学科ぶんの 1 学期です。次の順に 7 ページ、1 つの PDF にまとまって出ます。

```
経営・前期 → 経営・後期 → 会計・前期 → 会計・後期
→ 短大・前期 → 短大・後期 → 集中講義
```

> 印刷の画面で用紙が A3 になっていない場合は、「詳細設定」から A3・横向きに直してください。

**Excel（.xlsx）**

ファイルが保存されます。これまで手で作られていた時間割の様式に合わせてあります。

学科×学期で 6 シート。曜日を横に並べ、時限と年次で縦に区切ります。集中講義は各シートの右端の「集中」欄に、その学科・学期のぶんが入ります。

時限の欄には授業時間（1時限なら 8：50〜10：30）が入ります。曜日と時限が見分けやすいよう、升目に一つおきに薄い灰色を敷いてあります。

短期大学部のシートだけ、集中講義の一覧が表の下（左端）に入ります。曜日の欄が大学より 1 列多く、右に置くと横に長くなりすぎるためです。

開くと表示倍率 40% で開きます。A3 横 1 枚ぶんの幅があるので、100% では右端が画面からはみ出します。

**教室・抽選・人数の欄は空のまま出ます。** 読み込む Excel にその情報が無いためです。枠だけ用意してありますので、これまでどおり手で埋めてください。

### 設定

**AI モードを使う場合だけ**必要です。

| 項目       | 内容                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| API キー   | Google から取得したキーを貼り付けて「保存」。保存後は先頭数文字しか表示されません。このパソコンの中にだけ保存されます |
| モデル     | 使う AI の種類。通常は変更不要です                                                                                    |
| 再試行回数 | AI の答えが決まりに反していたときに、やり直す回数です。通常は 3 のままで構いません                                    |

> ⚠️ 「開発者向け：予備モデル」は開発用の項目です。実務では開かず、何も選ばないでください。

## 5. データの保存場所

| 場所                         | 内容                                                        |
| ---------------------------- | ----------------------------------------------------------- |
| `backend\.env`               | API キー                                                    |
| `backend\data\settings.json` | モデル名・再試行回数                                        |
| `backend\data\sessions\`     | 読み込んだ Excel と作成した時間割（新しいものから 10 回分） |
| `backend\logs\`              | 作業の記録（1 回の生成につき 1 ファイル、10 件まで）        |

いずれも必要になったときに自動で作られます。

うまく動かないときは、`backend\logs\` の中にある日時のついたファイルを担当者にお渡しください。原因を調べる手がかりになります。

## 6. 困ったときは

黒い画面に出るメッセージは英語です。よく出るものを挙げます。

| メッセージ                                            | 対処                                                                                                                                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Python was not found`                                | Python が入っていません。[1. 使いはじめる前に](#1-使いはじめる前に) に従って入れてから、`setup.bat` をもう一度実行してください。**「Add python.exe to PATH」のチェックを忘れていないか確認を。** |
| `Python 3.11 or newer is required`                    | Python は入っていますが古い版です。新しい版を入れてください                                                                                                                                      |
| `a .venv folder exists but was not built for Windows` | 別のパソコンからフォルダーごとコピーした場合に出ます。このフォルダーの中の `.venv` を削除してから、`setup.bat` をもう一度実行してください                                                        |
| `could not install the dependencies`                  | 部品の取り込みに失敗しました。インターネットにつながっているか確認して、`setup.bat` をもう一度実行してください                                                                                   |
| `the Python environment is missing`                   | 最初の準備がまだです。`setup.bat` を先に実行してください                                                                                                                                         |
| `port 8000 is already in use`                         | すでに起動しています。[3. 毎日の使い方](#3-毎日の使い方) の項をご覧ください                                                                                                                      |

<details>
<summary>生成は終わったが、未配置科目が残る</summary>

決まりを守ったままでは置けなかった科目です。結果画面の右側に科目名と担当の先生が出ます。

多くの場合、**非常勤の先生の出勤可能コマ数に対して、担当科目が多すぎること**が原因です。時間割の組み替えでは解消できないので、その先生の出勤可能日を増やしていただくか、担当科目を見直す必要があります。

未配置科目の一覧からマスへドラッグすれば、手で置くこともできます。その場合も決まりに反する置き方はできません。

</details>

<details>
<summary>画面の表示が古いまま変わらない</summary>

ブラウザが前回の表示を覚えていることがあります。`Ctrl` キーを押しながら `F5` キーを押して読み込み直してください。

</details>

<details>
<summary>上記以外</summary>

`backend\logs\` の中の、日時のついたファイルをご確認ください。どの段階で何が起きたかが記録されています。

</details>

## 7. 開発者向け

事務局へは `make-dist.sh` が作る zip を配ります。ここから下は、その中身を直す人のための覚え書きです。

### 構成

| 場所              | 内容                                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `backend/app/`    | FastAPI のアプリ本体。`ingest`（Excel 読込）・`constraints`（制約）・`scheduler`（生成）・`export`（書き出し）・`gemini`（AI）    |
| `backend/config/` | 学科ごとの編成規則、氏名の表記ゆれ、対になる科目などの設定 JSON                                                                   |
| `backend/tests/`  | 単体テストと E2E。`tests/js/` は Node の `vm` 上で画面の JS を直接動かす                                                          |
| `frontend/`       | 素の HTML / CSS / JavaScript。フレームワークも CDN も使っていません（事務局 PC がオフラインやプロキシ配下でも動くようにするため） |
| `docs/`           | 設計書と調査レポート                                                                                                              |
| `tools/`          | 開発用のスクリプト（踏襲の内訳を数える、Excel 出力の見た目を画像で確かめる）。配布 zip には入りません                                                                                   |

### 動かす

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/pip install -r backend/requirements-dev.txt   # テストを走らせる場合
npx playwright install chromium                         # E2E を走らせる場合

./start.sh          # http://localhost:8000/
./start.sh 8001 --no-browser
```

### テスト

```bash
cd backend
../.venv/bin/pytest tests/ -q     # 単体。E2E は pytest.ini の addopts で既定から外してある
../.venv/bin/pytest -m e2e -q     # E2E。実ブラウザで uvicorn を叩くので数分かかる
```

### 配布 zip を作る

```bash
./make-dist.sh      # timetable-generator.zip
```

アプリ・設定・画面・起動スクリプト・この README だけを詰めます。仮想環境・テスト・ドキュメント・API キー・実行時のデータは入りません（入っていたらビルドが止まります）。

> ⚠️ 事務局から受け取った実データ（`カリキュラム一覧*.xlsx` / `教員一覧*.xlsx`）は教員の実名を含むため追跡していません。開発時はリポジトリ直下に置いて使います。
